  • Reference: git archive 7afb7c5 frontend built with Vite; live: git archive HEAD frontend built the same way, same build number and commit. Both served by the same API binary built from this branch (CARGO_BUILD_JOBS=2), each on its own throwaway SQLite database with the same seed: a GitHub repository pool, a GitLab pool with an empty image, a GitLab pool with an image set, one GitLab connection "Acme / web".
  • Headless Chromium 1255 through Playwright 1.65.1 (installed in the session scratch directory, nothing added to the project), clock fixed to 2026-11-21 10:00 UTC, reduced motion, external requests blocked, three widths 360, 768, 1280 at heights 2600, 1900, 1500 so whole forms fit. Pixel counts by ImageMagick compare -metric AE; the page images in this report are the captures, with palette-reduced diffs and composites to keep the files small.
  • Both builds log the same console errors (500 from the repository and runner-group lists, because the seeded GitHub installation has no real encrypted token, and one blocked avatar image); none is new.
  • Servers stopped and throwaway databases deleted afterwards.
