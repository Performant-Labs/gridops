## Summary
BLOCK, with 2 block and 4 warn findings.
- **R1 is resolved.** Both R1 blocks are fixed: Part 2 now admits `sqlx::query` in the two filters and sets a 100 ms threshold, and Part 3 no longer retries the poll. R1 warns 3 to 7 are folded in.
- **Part 3 introduces a sibling of the R1 poll problem, on the command result.**
  - The retry deadline is the observation lease held in `Authority`. The heartbeat loop renews that lease while the command loop is retrying a result, so the deadline keeps moving.
  - A result that keeps failing with 503 is retried forever. Meanwhile heartbeats keep granting work authority to a host that never polls again.
- **One existing recovery test breaks by construction.** `an_api_restart_leaves_a_running_runner_alone` requires an API restart to produce a new agent session. Part 3 makes the session survive the restart, and the brief does not say what happens to that test.
