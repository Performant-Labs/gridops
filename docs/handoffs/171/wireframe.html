1c. Refusal states (existing error surface, new message case)

The GitLab access token is missing the manage_runner scope.

GitLab connection verified.
Message format is fixed by the API: "The GitLab access token is missing the {scope} scope." Scope is the first missing one in order create_runner, manage_runner, read_api. Never shows the token.
