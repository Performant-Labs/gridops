The criterion is now testable — an implementer can write the test-only descriptor — but the acceptance criterion remains incomplete as a specification of what "returns a value" means for the test writer. Must amend the criterion to name the `PostCreateReveal` type and state that the test-only descriptor's hook returns an object conforming to it (e.g. "a `PostCreateReveal` with a fixed `value`"), so the criterion is self-contained and verifiable against the type contract.
