## Summary
BLOCK, with 2 block findings and 8 warn findings. Every item edits the object that already owns the behaviour, so there is no parallel path and no layering problem. The block findings are both about the contract with #204. The brief exists so that it "must land before #204: #204's independent Python oracle computes from the design doc".
