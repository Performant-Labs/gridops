### WARN findings
- **[W-1]** crates/gridops-core/src/autoscaling.rs (`gitlab_job_candidates` CTE) — a job duplicated across a project and its group connection whose project-connection row is terminal (`success`) while the group-connection row is still `pending` counts as demand: the D8 `IN`-list filter (required by A-B3) excludes the terminal row before the "highest tier of its rows" rule can see it. The poll self-corrects within `GITLAB_JOB_CHECK_AGE_MS` + one poll via `job`, so it is bounded staleness, but a pool can be scaled for a finished job for up to ~5+ minutes. Recommendation: note it as a known issue, or have the conclusion step consider duplicate rows on the same `base_url` when concluding.
- **[W-2]** crates/gridops-reconciler/src/gitlab_poll.rs (`check_stale_jobs`) — rows recorded under a connection for a project that a group connection no longer lists (project removed from the group) are never in `listed`, so they are re-checked via `job` every `GITLAB_JOB_CHECK_AGE_MS` forever while GitLab still reports them active (e.g. a long-running pipeline). Acceptable but worth documenting; same exposure as any long-running job.
- **[W-3]** crates/gridops-reconciler/src/gitlab_poll.rs (`check_stale_jobs` ordering) — the brief's A2-B1 orders within each status tier by `created_at, id`; the round-3 amendment says "least-recently-checked (`updated_at`) within the A2-B1 status order". The implementation orders by `updated_at, created_at, id`. This matches round 3 but not the round-2 text it replaced; confirm #140/#139 share the same reading so the two writers don't diverge.
- **[W-4]** crates/gridops-reconciler/src/main.rs (`gitlab_credentials`) — an invalid `base_url` returns `Err` from `poll_connection` (via `?` on `gitlab_credentials`), which surfaces as `Interrupted::Failed` and is logged per connection — fine — but a malformed stored URL therefore disables the whole connection including its conclusion step, which needs no GitLab calls for the pending-list part only. Marginal; consider treating it as "no credentials" or logging at warn once.
- **[W-5]** crates/gridops-reconciler/Cargo.toml — this file is not in the brief's allowed file list ("the files above plus tests, plus the D18 local copy..."). The dev-dependency is arguably required for the `FakeGitLab` tests, but it is an unstated scope extension; flag it for the orchestrator (and see NV-5 for the feature-unification side effect).
