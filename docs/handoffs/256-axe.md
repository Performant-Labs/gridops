## How it ran

The pass is the repository's own browser test, `tests/a11y/fleet-health-axe.spec.ts`, pointed at a
running GridOps instead of its recorded answers:

```sh
# 1. The #204 walkthrough's fleet, seeded around the current hour into a new scratch database.
GRIDOPS_FLEET_HEALTH_WALKTHROUGH_DB=/tmp/fh256-walk/gridops.sqlite CARGO_BUILD_JOBS=2 RUST_TEST_THREADS=2 \
  cargo test -p gridops-api --bin gridops-api seed_for_walkthrough -- --ignored
# 2. An administrator and a member with sessions, inserted into that database by a scratch script
#    (/tmp/fh256-walk/scripts/users.py, outside the repository). It also generates a session secret
#    and an encryption key and writes them and the two session cookies to a 0600 env file; none of
#    them is recorded here.
# 3. The SPA and the API (debug build) serving it, on loopback.
npm run build
GITHUB_CLIENT_ID=walkthrough-placeholder GITHUB_CLIENT_SECRET=walkthrough-placeholder \
GRIDOPS_FLEET_ALLOW_LOOPBACK_HTTP=true GRIDOPS_DATABASE_PATH=/tmp/fh256-walk/gridops.sqlite \
GRIDOPS_API_BIND=127.0.0.1:18256 GRIDOPS_BASE_URL=http://127.0.0.1:18256 GRIDOPS_WEB_ROOT=$PWD/dist \
GRIDOPS_SESSION_SECRET=… GRIDOPS_ENCRYPTION_KEY=… ./target/debug/gridops-api
# 4. The axe pass, live, one JSON line per scan.
GRIDOPS_A11Y_BASE_URL=http://127.0.0.1:18256 GRIDOPS_A11Y_ADMIN_SESSION=… GRIDOPS_A11Y_MEMBER_SESSION=… \
GRIDOPS_A11Y_REPORT=/tmp/fh256-walk/live-report.jsonl npx playwright test
```

Axe ran through `@axe-core/playwright` 4.14.1 with the walkthrough's tags (`wcag2a`, `wcag2aa`,
`wcag21a`, `wcag21aa`, `wcag22aa`, `best-practice`) over the whole page, with
`timezoneId: America/Los_Angeles` and `reducedMotion: reduce`. The theme was set as the
walkthrough set it (`localStorage['gridops-theme']` plus `colorScheme` emulation), and the test
checks `<html class>` before each scan. The seeded fleet: io, Jupiter, callisto, europa (offline)
and MacBookPro (budget 0, no score); fleet score 45 at 24 h.

Without `GRIDOPS_A11Y_BASE_URL` the same test serves `dist/` with `vite preview` and answers the API
from `tests/a11y/api-fixtures.json`, the responses recorded from this run
(`GRIDOPS_A11Y_RECORD`): that is `npm run test:a11y`, which CI runs after the build, so a serious or
critical violation fails the web job.
