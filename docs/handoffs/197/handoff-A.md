## Summary
BLOCK, with 4 block findings and 9 warns.

The plan's core idea is consistent with the codebase: a wave-0 contract of types, a trait with a fake, stubs and sibling `*_tests.rs` files, like #137. But the brief is wrong in places, and those errors would become the owners file and the contract tests:
- #190's insert sites are wrong. Most of them are test code, and the real poll writer is in reconciler `main.rs`.
- The Vitest contract tests would never be collected.
- Several hooks in shared files are not on the brief's list, so wave-1 agents would have to edit files they don't own.
- The endpoint's auth would serve a fleet-wide cached response to callers who should not see all of it.

All four need a brief amendment before T writes tests.
