  1. 1Platform first. The chooser lists every descriptor in platforms that is creatable-or-linkable (has a create binding or an external “connect” link). A single-platform registry skips straight to step 2.
  2. 2Dialog renders only the chosen descriptor’s fields from its declarative list (label, input type — text/secret, required, help). Secret fields are masked and autocomplete=off. The dialog has no per-platform branches.
  3. 3Submit “Connect workspace” label comes from the descriptor (createLabel); disabled while submitting and while required fields are empty (native required validation). On success: dialog closes, toast {platform name} connected., list refreshes (router invalidate).
  4. 4Error stays in the dialog (does not close), field values kept except the secret is kept too so the user can retry.
  5. 5Post-create hook (optional per descriptor). If it returns a value the dialog swaps to the reveal (C4) instead of closing; if it returns nothing the dialog closes as in note 3. GitHub and Bitbucket return nothing today.
  6. 6Focus: first field on step 2; Copy in C4 uses the existing CopyButton and toast.
