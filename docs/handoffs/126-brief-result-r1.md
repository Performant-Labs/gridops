### WARN findings

**[W-2]** Item 5 permits Docker-daemon tests "if the existing suite already has a Docker-gated pattern," while decision 10 says flatly "No test needs a Docker daemon." **[W-3]** Edge cases not covered: an image whose WorkingDir is `/` or `/actions-runner` with no `externals` is handled, but an `externals` directory that is itself a symlink in the image, or an image id containing characters awkward for a directory name (`sha256:…` is legal on Linux but check any agent-side sanitization), are unaddressed. — Add a sentence on how the cache directory name is derived from `{{.Id}}` and that a symlinked `externals` in the image is either followed or rejected with `Configuration, false`.
