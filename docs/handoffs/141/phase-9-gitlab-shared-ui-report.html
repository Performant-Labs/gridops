What I see different

  • 360 and 320, GitLab connection rows (the fix): the four buttons (Edit, Verify, Rotate webhook secret, Remove) now wrap onto two lines, right-aligned, instead of running off the left edge. Edit is fully visible and tappable. At 390 the same wrap applies; from 414 up all four fit on one line.
  • 768 and 1280, GitLab connection rows: no change from the first audit. On a long project path the Project badge drops under the name and the path is cut with an ellipsis. Cosmetic, not blocking.
  • Connections page (intended, unchanged since cycle 1): one new row “GitLab” with “No GitLab projects or groups are connected yet.” when none exist. Add connection lists GitLab as a third choice.
  • Webhooks and delivery sheet (intended): a platform badge; at 1280 the list rows show it, below 1024 px only the sheet does.
  • Not changed at all: the new-pool form, its Targets picker at rest, a repository pool’s settings, and the Runners list are pixel-identical to the build before #141 at all three widths.
  • Every other GitLab state (add form, errors, reveal, rotate, verify error, pool picker, Platform options, pool settings, runner link, deliveries) is pixel-identical to the first audit, apart from the connection list showing behind dialogs at 360, which takes the new row layout.
